# 法律函件骨架（dsh-legal-notice）

**什么时候用**：催告欠款、通知解除合同、给对方发正式函件前的文书起草。产物是**骨架**，必须人工核实事实后使用。
用户会说：帮我起草一份催告函、这个合同我想解除怎么通知、给对方发个律师函。

## 怎么用

```bash
<cli 路径> --type demand --party-a 发函方 --party-b 收函方 --contract 合同 --breach 违约事实 --amount 金额 --days 宽限天数 --out 目录
<cli 路径> --type termination --clause "第X条" --effective 2026-12-01 --out 目录
<cli 路径> --type lawyer --firm 律所 --lawyer 律师 --claim "于10日内付清全部欠款" --out 目录
```

## 三类模板

| 类型 | 产物 | 内置要点 |
|---|---|---|
| demand | 催告函 | 欠付事实 + 宽限期 + 逾期后果（利息/违约金/解除权保留） |
| termination | 解除通知书 | 违约事实 + 解除依据 + 结算移交 + 异议途径（民法典第 563/565 条） |
| lawyer | 律师函 | 委托关系 + 事实陈述（以委托人提供为准）+ 要求 + 逾期追责 |

## 怎么用产物

1. 产物 = .md（改写）+ .html（A4 打印版）；附注三条（事实核实 / EMS 送达留证 / 不构成法律意见）发函前删除
2. 送达方式影响举证：EMS 面单注明文件名称、拍照封存
3. 重大争议请委托律师出具正式函件
